## Где задавать

| Уровень | Где в панели |
| --- | --- |
| Приложение | [«Архитектура»](/docs/structure/architecture#панель-сервиса) → панель сервиса → вкладка **«Переменные»** или [«Окружения»](/docs/structure/environments#переменные-окружения) → «Переменные окружения», в поле «Где действует» — группа **«Сервис»**. При создании сервиса — в поле «Переменные окружения» или «Переменные» мастера |
| Окружение | «Окружения» → «Переменные окружения», группа **«Окружение»** |
| Проект | Там же, группа **«Весь проект»** |

На странице «Окружения» поле **«Где действует»** предлагает проект, его окружения и их сервисы в пределах
[области](/docs/structure/scope), выбранной в шапке, и с учётом ваших прав. Тип «Ссылка на сервис»
доступен, только когда выбран сервис: ссылка хранится у сервиса, который её читает.

Имя переменной — латиница, цифры и подчёркивание, не может начинаться с цифры.

В контейнер приложения попадают только **переменные приложения**. Переменные окружения и проекта — это
общие значения: приложение получает их, только если сослаться на них, см. [ниже](#ссылки-на-переменные).

## Тип значения

| Тип | Что это |
| --- | --- |
| **Обычное значение** | Текст, который видно в панели |
| **Секрет** | Хранится зашифрованным и скрыт в списках |
| **Ссылка на сервис** | Значение берётся из базы PostgreSQL, сервиса из шаблона, например Valkey, или домена другого приложения. Только для переменных приложения |

## Когда используется

Поле **«Использовать при»**:

| Вариант | Когда переменная доступна |
| --- | --- |
| Только запуск | В работающем контейнере. Вариант по умолчанию для новых переменных |
| Только сборка | Во время сборки образа |
| Сборка и запуск | И во время сборки, и в работающем контейнере |

<Callout type="warn">
  Переменные для сборки (например, `NEXT_PUBLIC_*` для Next.js или `RAILPACK_*` для настройки сборки)
  отметьте **«Сборка и запуск»** или **«Только сборка»**. С вариантом по умолчанию они
  до сборки не дойдут.
</Callout>

Переменные, созданные до появления этапов, работают и при сборке, и при запуске.

## Секреты

- Значение секрета хранится зашифрованным и не показывается в списках. Посмотреть или скопировать его
  можно отдельно — **«Показать значение»**. Каждый просмотр и копирование записываются в
  [журнал аудита](/docs/access/audit), а само значение не записывается.
- Чтобы поменять секрет, отметьте **«Заменить сохранённое значение»** и введите новое. Если не отмечать,
  сохранённое значение не изменится.
- В журналах развёртывания значения секретов маскируются.

<Callout type="info">
  Маскируются только сами значения. Если приложение выводит секрет в изменённом виде (например, в base64),
  панель его не узнает. Исходные файлы журналов на сервере остаются как есть.
</Callout>

## Ссылки на сервисы

Тип **«Ссылка на сервис»** избавляет от копирования адресов и паролей: значение подставляется из источника
в момент развёртывания.

| Источник | Что можно подставить |
| --- | --- |
| [PostgreSQL](/docs/databases/postgres) | Строку подключения, хост, порт, имя базы, пользователя или пароль — через внутреннюю сеть или внешний адрес |
| [Valkey](/docs/deployments/templates#сервисы-без-веб-интерфейса) | Адрес подключения `redis://:<пароль>@<хост>:6379`, хост, порт или пароль `VALKEY_PASSWORD` |
| Meilisearch | Адрес `http://<хост>:7700`, хост, порт или ключ API — мастер-ключ `MEILI_MASTER_KEY` |
| MinIO | Адрес S3 API `http://<хост>:9000`, хост, порт, пользователя `MINIO_ROOT_USER` или пароль `MINIO_ROOT_PASSWORD` |
| Ollama | Адрес API `http://<хост>:11434`, хост или порт |
| LocalAI | Адрес `http://<хост>:8080`, хост, порт или ключ API `LOCALAI_API_KEY` |
| Домен другого приложения | Адрес приложения в этом же окружении |

Источник выбирается в поле **«Источник значения»**: в списке — сервисы этого окружения, например
«valkey · Адрес подключения · внутренняя сеть».

- **Внутренняя сеть** работает, только если приложение и база на одном сервере, и только при запуске.
  Для сборки выберите внешнее подключение.
- **Внешний адрес** требует открытого [внешнего порта](/docs/databases/postgres#внешнее-подключение) базы.
- **Сервисы из [шаблонов](/docs/deployments/templates)** доступны только по внутренней сети: они должны
  быть на одном сервере с приложением и в общей сети, а ссылка работает только при запуске. Другие
  сервисы в списке не появятся. Сервис узнаётся по образу, поэтому подходит и сервис из Docker-образа
  `valkey/valkey`, `getmeili/meilisearch`, `minio/minio`, `ollama/ollama` или `localai/localai`. Шаблон
  «Open WebUI + Ollama» как источник не подходит.
- Пароль, пользователь и ключ API берутся из переменных самого сервиса, например `VALKEY_PASSWORD`. Если
  такой переменной у него нет, развёртывание приложения остановится с ошибкой.
- Выбор ссылки не открывает порты и не меняет сети. Сохранённый адрес не означает, что соединение работает.
  Доступ к базе можно [проверить на странице «Архитектура»](/docs/structure/architecture#проверить-соединение).

Мастер GitHub создаёт такие ссылки сам, если отметить «Создать PostgreSQL» или «Создать Valkey», см.
[База данных и Valkey](/docs/quick-start#база-данных-и-valkey).

Значения ссылок, как и секреты, маскируются в журналах. Пароль из адреса подключения маскируется и
отдельно — на случай, если приложение выводит его без адреса.

## Ссылки на переменные

В обычном значении переменной приложения можно сослаться на другую переменную:

| Синтаксис | Откуда берётся значение |
| --- | --- |
| `${{project.KEY}}` | Переменная `KEY` проекта |
| `${{environment.KEY}}` | Переменная `KEY` окружения |
| `${{KEY}}` | Другая переменная `KEY` этого же приложения |

Например, общий адрес API задаётся один раз в окружении, а приложения ссылаются на него:

```bash
API_URL=${{environment.API_URL}}
```

Ссылаться можно и на секрет — подставится его значение. Переменная, на которую ссылаются, должна быть
доступна на том же этапе: ссылка из переменной для сборки на переменную «Только запуск» не сработает.

<Callout type="warn">
  Если переменной, на которую ссылается значение, нет, развёртывание завершится ошибкой.
</Callout>

## Когда применяются изменения

Значения переменных, секретов и ссылок фиксируются в момент запроса на развёртывание. Изменения после этого
действуют только на новые развёртывания. Откат и повтор используют сохранённые значения. Если источник
ссылки удалён или значение не удаётся расшифровать, развёртывание остановится, а не подставит пустую строку.

Новое окружение не копирует секреты и ссылки из других окружений — задайте их заново.
