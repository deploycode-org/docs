## Уровни переменных

Переменные задаются на трёх уровнях:

| Уровень | Действует на |
| --- | --- |
| Проект | Все окружения и сервисы проекта |
| Окружение | Все сервисы окружения |
| Приложение | Одно приложение |

<Callout>Порядок переопределения при совпадении имён — скоро.</Callout>

## Когда применяются изменения

Значения на момент запроса на деплой входят в **конфигурацию деплоя**. Изменения после этого не
влияют на уже запущенный деплой — нужен новый деплой.
