---
title: Патчи
description: Изменение файлов репозитория перед сборкой без коммита.
---

**Патч** создаёт, изменяет или удаляет файл в исходниках приложения перед сборкой. Репозиторий при этом
не меняется — удобно, когда нужно поправить конфиг под конкретный сервер или окружение.

| Действие | Что происходит |
| --- | --- |
| Создать | Добавляет файл по указанному пути |
| Изменить | Заменяет содержимое существующего файла |
| Удалить | Удаляет файл перед сборкой |

На один путь в приложении — один патч. Патч можно временно выключить, не удаляя.

## Когда лучше обойтись без патча

Если изменение нужно во всех окружениях, закоммитьте его в репозиторий: так его увидят ревью и история git.
