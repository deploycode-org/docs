Файловая система контейнера пересоздаётся при каждом деплое. Всё, что должно пережить деплой, храните в
**именованных томах** — Docker-томах на сервере.

## Добавление тома

**Настройки сервиса → «Именованные тома»**: укажите том и **путь в контейнере**, куда его смонтировать,
например `/app/uploads`. Изменения применяются при следующем развёртывании.

Удаление строки только перестаёт монтировать том — сам Docker-том с данными остаётся на сервере.

Подходит для загрузок пользователей, кешей, файлов SQLite.

<Callout type="warn">
  Данные в томах не входят в [конфигурацию деплоя](/docs/concepts) и не переносятся при откате.
  Для их защиты создавайте [снимки томов](/docs/backups/volumes).
</Callout>
