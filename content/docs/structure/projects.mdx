**Проект** — именованная группа окружений внутри [организации](/docs/structure/organizations). Обычно проект —
это продукт или клиент: например, студия может завести отдельный проект на каждого клиента.

## Создание проекта

Проект создаётся мастером **«Запустить приложение»** вместе с первым сервисом — кнопки **«Новый проект»** в
списке проектов и **«Создать проект»** в шапке. См. [Быстрый старт](/docs/quick-start).

Мастер создаёт в проекте окружение `production` — [окружение по умолчанию](/docs/structure/environments#окружение-по-умолчанию).
Остальные окружения добавляются отдельно.

## Страница проекта

- если сервисов больше одного — сводка: сервисы, последнее развёртывание, серверы, окружения;
- список сервисов — по окружениям, если их несколько, и кнопка **«Новый сервис»**.

Название и описание проекта меняются кнопкой с карандашом рядом с названием.

## Переменные проекта

Переменные уровня проекта задаются на странице [«Окружения»](/docs/structure/environments#переменные-окружения)
с областью **«Весь проект»**. Они видны во всех окружениях проекта, а приложения получают их по ссылке
`${{project.KEY}}` — см. [Переменные окружения](/docs/deployments/variables).

## Доступ к проекту

Владелец и администраторы видят все проекты, остальные роли — только созданные ими самими. Что можно
делать в проекте, определяет [роль](/docs/access/roles).

## Удаление

В списке проектов: меню проекта → **«Переместить в корзину»**, затем введите название проекта. Проект со
всеми окружениями и сервисами попадёт в [корзину](/docs/structure/trash) на 7 дней. Адреса `deploycode.app`
освобождаются сразу, запущенные ресурсы на сервере не удаляются.
