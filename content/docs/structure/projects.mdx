**Проект** — именованная группа окружений внутри [организации](/docs/structure/organizations). Обычно проект —
это продукт или клиент: например, студия может завести отдельный проект на каждого клиента.

## Создание проекта

<Callout>Описание шагов в панели — скоро.</Callout>

## Окружение по умолчанию

При создании проекта появляется окружение по умолчанию. Остальные окружения добавляются отдельно —
см. [Окружения](/docs/structure/environments).

## Переменные проекта

[Переменные](/docs/deployments/variables) уровня проекта действуют во всех его окружениях.

## Доступ к проекту

Владелец и администраторы видят все проекты, остальные роли — только созданные ими самими. Что можно делать в проекте, определяет [роль](/docs/access/roles).
