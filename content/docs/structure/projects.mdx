**Проект** — именованная группа окружений внутри [организации](/docs/structure/organizations). Это единица, на которую участникам выдаётся
доступ: например, студия может завести отдельный проект на каждого клиента.

## Создание проекта

<Callout>Описание шагов в панели — скоро.</Callout>

## Окружение по умолчанию

При создании проекта появляется окружение по умолчанию. Остальные окружения добавляются отдельно —
см. [Окружения](/docs/structure/environments).

## Переменные проекта

[Переменные](/docs/deployments/variables) уровня проекта действуют во всех его окружениях.

## Доступ к проекту

Кто видит проект и что может в нём делать, определяют [роли и группы доступа](/docs/access/roles).
