**Сервис** — всё, что можно задеплоить в [окружение](/docs/structure/environments). Сейчас поддерживаются два
вида:

| Вид | Что это |
| --- | --- |
| Приложение | Собирается из репозитория GitHub — см. [Сборка и деплой](/docs/deployments) |
| PostgreSQL | База данных на вашем сервере — см. [PostgreSQL](/docs/databases/postgres) |

Новый сервис создаётся кнопкой **«Новый сервис»** — в списке сервисов или на странице проекта.

## Список сервисов

Страница **«Сервисы»** показывает сервисы выбранной [области](/docs/structure/scope): вид, статус
развёртывания, ветку, проект и окружение. Есть поиск по названию, ветке, проекту и окружению.

| Статус | Что значит |
| --- | --- |
| Развёрнут | Последнее развёртывание прошло успешно |
| Разворачивается | Идёт развёртывание |
| Ошибка развёртывания | Последнее развёртывание завершилось ошибкой |
| Не развёрнут | Сервис ещё не развёртывали или остановили |
| Развёртывание отменено | Последнее развёртывание отменили |

## Страница приложения

На обзоре приложения — кнопки **«Настройки»**, **«Пересобрать»**, **«Развернуть»** и блоки:

- **Состояние в Docker** — что сейчас работает на сервере;
- **Сервер**, **Последнее развёртывание**, **Репозиторий**, **Домены**;
- лента развёртываний и [превью](/docs/observability/previews) сайта.

### Состояние в Docker

| Состояние | Что значит |
| --- | --- |
| Сервис запущен | Все реплики работают |
| Не все реплики запущены | Docker ещё запускает часть реплик |
| Сервис остановлен | В Docker задано 0 реплик |
| Сервис не найден на сервере | На выбранном сервере такого сервиса нет |
| Состояние неизвестно | Панель не смогла проверить сервер |

Состояние в Docker не зависит от результата последнего развёртывания: если новое развёртывание упало,
предыдущая версия может продолжать работать.

### Настройки приложения

| Раздел | Что настраивается |
| --- | --- |
| Репозиторий | [Аккаунт GitHub, репозиторий, ветка, путь сборки](/docs/deployments/github#репозиторий-и-ветка-сервиса) |
| Сборка и запуск | [Команды и результат сборки](/docs/deployments/builders) |
| Реестр образов | [Куда сохранять собранные образы](/docs/deployments/registry) |
| Именованные тома | [Постоянные данные](/docs/deployments/volumes) |
| Опасная зона | Перемещение в [корзину](/docs/structure/trash) |

Переменные приложения задаются в [панели сервиса на «Архитектуре»](/docs/structure/architecture#панель-сервиса),
домены — в разделе [«Домены»](/docs/networking).

<Callout type="info">
  Число реплик и лимиты CPU и памяти для приложений в панели пока не настраиваются. Для PostgreSQL лимиты
  есть в «Расширенных настройках».
</Callout>
