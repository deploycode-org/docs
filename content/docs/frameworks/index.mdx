Приложения без `Dockerfile` собираются [Railpack](/docs/deployments/builders): он определяет язык по
файлам в репозитории, ставит зависимости, собирает и запускает приложение. Обычно ничего настраивать не
нужно. Если в каталоге приложения есть `Dockerfile`, образ собирается по нему, и советы ниже про Railpack к
нему не относятся.

## Порт — главное, что нужно проверить

Traefik отправляет трафик на **порт контейнера**, указанный в [домене](/docs/networking). По умолчанию
это **3000**, а если в `Dockerfile` есть `EXPOSE`, мастер запуска берёт порт из него. Приложение должно
слушать этот порт на всех интерфейсах (`0.0.0.0`), иначе домен вернёт ошибку 502.

Приложению, собранному из репозитория, DeployCode передаёт этот порт в переменной `PORT`. Берётся порт
адреса на `deploycode.app`, а если его нет — самого старого домена. Next.js, FastAPI, Flask, Django,
Laravel и статические сайты Railpack читают `PORT`, поэтому обычно ничего настраивать не нужно. В своём
коде на Node.js или Go читайте порт из `PORT`.

- Если вы задали `PORT` в переменных приложения сами, DeployCode его не меняет. Тогда порт в домене должен
  совпадать с ним.
- Сервису из [Docker-образа](/docs/deployments/docker-image) `PORT` не передаётся: порт выбрал автор образа.
- Приложение узнаёт новый порт только при следующем развёртывании. После смены порта в домене панель
  предложит **«Развернуть»**.
- У сервиса без домена, например у фонового обработчика, `PORT` не задаётся.

Без `PORT` фреймворки слушают свои порты по умолчанию:

| Что запускается | Порт по умолчанию |
| --- | --- |
| Next.js (`next start`) | 3000 |
| FastAPI, Flask | 8000 |
| Laravel, статические сайты и SPA | 80 |
| Node.js, Go | Тот, что задан в коде |

Если приложение всё же слушает другой порт или только `127.0.0.1`, на [странице сервиса](/docs/structure/services#обзор-сервиса)
появится «Не отвечает на порту …», а если найден открытый порт — кнопка **«Указать порт …»**, которая
переведёт на него адрес.

## Версии языков

Railpack берёт версию из файлов проекта (`.nvmrc`, `.python-version`, `go.mod`, `composer.json` и т. д.).
Её можно переопределить переменной `RAILPACK_<ЯЗЫК>_VERSION` с этапом «Сборка и запуск» — подробности на
странице каждого языка.

## Монорепозитории

Если приложение лежит в подкаталоге, укажите **путь сборки** в настройках приложения. Для workspace в
Node.js см. [Node.js](/docs/frameworks/nodejs#монорепозитории).
