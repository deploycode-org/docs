- **Роль** определяет *какие действия* разрешены.
- **Группа доступа** определяет *в каких проектах* — назначает участникам проекты с ролью для каждого.

## Встроенные роли

Роль `owner` есть только у [владельца организации](/docs/structure/organizations#владелец); выдать её через приглашение или смену роли нельзя.
