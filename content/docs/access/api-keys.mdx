Создание API-ключей и публичный REST API пока недоступны в панели. Раздел появится вместе с ними.

Как будут работать ключи:

- ключ принадлежит пользователю и привязан к одной организации;
- запросы по ключу выполняются с ролью этого пользователя в организации — ключ не даёт больше прав, чем
  у его владельца;
- если пользователь покидает организацию, ключ перестаёт работать.

См. также [REST API](/docs/reference/api).
