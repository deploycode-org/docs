В DeployCode два вида приглашений:

| Приглашение | Что даёт |
| --- | --- |
| **Приглашение в организацию** | Делает существующего пользователя участником организации |
| **Приглашение на платформу** | Позволяет создать аккаунт, пока регистрация открыта только по приглашениям |
