## Журнал развёртывания

Журнал показывает всё, что происходило при сборке и запуске: клонирование репозитория, сборку Railpack,
запуск контейнеров. Пока развёртывание идёт, журнал обновляется в реальном времени.

Где открыть:

- в истории развёртываний — **«Открыть журнал»** в меню или вкладка **«Логи»** в карточке развёртывания;
- на странице сервиса — колонка **«Логи»** в ленте «Последние развёртывания»;
- в мастере первого запуска — **«Показать логи»** во время сборки и **«Открыть логи»** после ошибки.

Возможности просмотра:

- поиск по журналу с переходом между совпадениями;
- фильтр по уровню: ошибки, предупреждения, успешные операции, информация, отладка;
- перенос строк, копирование видимых строк, скачивание файла `.log`.

Журналы хранятся на сервере, где шла сборка, — для 10 последних развёртываний каждого приложения.

## Терминал сервера

На странице сервера, вкладка **«Терминал»**, открывается SSH-сессия прямо на сервере — через неё можно,
например, посмотреть логи контейнеров командой `docker service logs`.

Терминал открывает доступ ко всему серверу, поэтому он доступен только участникам с правом создавать серверы.
