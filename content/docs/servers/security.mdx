## Доступ панели к серверу

- Панель подключается по SSH с ключом, который DeployCode создаёт для сервера при подключении. Пароли
  и ваши приватные ключи панели не нужны.
- Пользователь — `root` или пользователь с sudo без пароля: права нужны для установки Docker и
  управления сервисами. Под обычным пользователем установка идёт через sudo, а развёртывания потом — под
  этим пользователем, которого установка добавила в группу `docker`.

## Защита от атак

Встроенная защита [CrowdSec](/docs/servers/firewall) пока не включается из панели. Ограничьте входящие
подключения файрволом облака или ОС.

## Отключение сервера от DeployCode

См. [Удаление сервера](/docs/servers#удаление-сервера). Ключ, который DeployCode создал для сервера,
удаляется из панели вместе с ним.

На своём сервере удаление в панели ничего не трогает: контейнеры, данные и ключ DeployCode в
`~/.ssh/authorized_keys` остаются. Удалите ключ вручную, если панель больше не должна иметь доступ.
ВМ, созданную из панели в reg.ru Cloud или Yandex Cloud, можно удалить у провайдера вместе с сервером.
