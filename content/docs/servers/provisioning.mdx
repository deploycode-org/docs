При подготовке на сервер устанавливаются:

| Компонент | Зачем |
| --- | --- |
| Docker (Swarm) | Запуск сервисов |
| Railpack | Сборка приложений без Dockerfile |
| Traefik | Reverse proxy и TLS-сертификаты |
| rclone | Работа с хранилищами и бэкапами |
