## Операционная система

Поддерживаются популярные дистрибутивы Linux: Ubuntu, Debian, CentOS, RHEL, Rocky Linux, AlmaLinux,
Fedora, Oracle Linux, Amazon Linux, openSUSE, Arch, Alpine и производные от них.

## Ресурсы

| Ресурс | Рекомендация |
| --- | --- |
| Диск | SSD от 40 ГБ — образы и кеш сборки занимают место быстро |
| Память | От 2 ГБ; для сборки Next.js и похожих фреймворков — 4 ГБ или файл подкачки, см. [Не хватает памяти при сборке](/docs/troubleshooting/builds#не-хватает-памяти-при-сборке) |
| CPU | Зависит от приложений: сборка по умолчанию выполняется на том же сервере |

## Диск

DeployCode проверяет свободное место перед каждой сборкой:

| Свободно | Что происходит |
| --- | --- |
| Меньше 12 ГБ или диск заполнен на 85% | Предупреждение «На сервере мало места» |
| Меньше 8 ГБ или меньше 200 000 инодов | Сборка не начинается, пока место не освободят |

Освободить место можно на странице сервера, в карточке **«Очистка диска»**.

## Сеть и порты

| Порт | Зачем |
| --- | --- |
| 22/TCP (или ваш SSH-порт) | Подключение панели к серверу |
| 80/TCP | HTTP и выпуск сертификатов Let's Encrypt |
| 443/TCP, 443/UDP | HTTPS и HTTP/3 |

На портах 80 и 443 работает Traefik. Если их занимает другой веб-сервер (nginx, Apache), настройка
сервера предупредит об этом — остановите его, иначе домены не заработают.

## Пользователь

DeployCode подключается по SSH под пользователем, которого вы укажете при добавлении сервера:

- `root` — вариант по умолчанию;
- или обычный пользователь с **sudo без пароля**. Без него настройка остановится с ошибкой
  «Non-root user requires passwordless sudo access».
