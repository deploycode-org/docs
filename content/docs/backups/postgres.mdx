## Создать копию вручную

На вкладке **Postgres** выберите базу и нажмите **«Создать копию»**. Для одной базы одновременно
выполняется одна копия: повторное нажатие не создаёт вторую.

## Автоматическое копирование

В разделе **«Политика копирования»**:

| Настройка | Значения |
| --- | --- |
| Автоматическое копирование | Выключено по умолчанию. После включения первая копия начнётся в течение минуты |
| Периодичность | Каждые 6 часов, каждые 12 часов, каждый день (по умолчанию), каждую неделю |
| Хранить, дней | От 1 до 365, по умолчанию 7 |

Нажмите **«Сохранить политику»**. Ниже видно, когда следующий запуск.

Ручная копия при включённом расписании сдвигает следующий автоматический запуск на один интервал.

## Что входит в копию

Копия — это дамп одной базы сервиса в формате PostgreSQL custom (`pg_dump -Fc`), без владельцев объектов
и прав доступа (`--no-owner --no-acl`).

## Срок хранения

Раз в сутки копии старше срока хранения удаляются из хранилища и получают статус «Срок истёк». Всегда
сохраняются:

- последняя успешная копия — даже если её срок истёк;
- копии, из которых сейчас идёт восстановление.

Удалить копию вручную нельзя.

## История копий

В **«Истории копий»** — последние 50 запусков: время, статус, размер и проверка восстановления.

| Статус | Что значит |
| --- | --- |
| В очереди | Копия ждёт запуска |
| Создаётся | Идёт дамп |
| Готова | Копия загружена в хранилище |
| Ошибка | Копия не создана — причина видна в строке |
| Срок истёк | Копия удалена по сроку хранения |

### Проверка восстановления

Отметка «Проверка восстановления» появляется, когда копию реально восстановили на другом сервере и
проверили: контрольная сумма совпала, новая база запустилась и отвечает на запросы. Содержимое данных с
исходной базой при этом не сравнивается.

Самый надёжный способ убедиться, что копиям можно доверять, — периодически
[восстанавливать](/docs/backups/restore) их на другой сервер.

## Если копия не создалась

| Ошибка | Что проверить |
| --- | --- |
| Контейнер Postgres недоступен | База запущена? См. страницу сервиса |
| Ошибка pg_dump | Журнал базы — «Показать логи» на странице PostgreSQL |
| Хранилище копий не настроено | Обратитесь в поддержку DeployCode |
