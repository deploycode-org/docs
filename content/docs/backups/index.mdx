DeployCode делает резервные копии двух видов данных, которые не восстанавливаются из git:

<Cards>
  <Card title="PostgreSQL" href="/docs/backups/postgres">Дампы баз данных по расписанию.</Card>
  <Card title="Тома приложений" href="/docs/backups/volumes">Данные из Docker-томов.</Card>
</Cards>

Бэкапы загружаются в объектное хранилище; для каждого сохраняется контрольная сумма SHA-256, размер и
статус. Восстановление описано в разделе [Восстановление](/docs/backups/restore).
