---
title: Тома приложений
description: Снимки именованных томов приложения.
---

Снимок сохраняет содержимое [именованных томов](/docs/deployments/volumes) приложения: каждый том
упаковывается в отдельный архив, а для всех архивов записываются контрольные суммы SHA-256.

## Ограничения

- Снимок делается **только вручную** — расписания нет.
- Приложение должно быть **остановлено** на всё время снимка: так данные в томе не меняются во время копирования.
- Поддерживаются только локальные именованные тома на одном сервере. Если у приложения есть bind-монтирования
  или файлы, снимок создать нельзя.
- Снимки не удаляются со временем.

## Создать снимок

1. На странице **«Резервные копии»** откройте вкладку **«Тома приложений»** и выберите приложение.
2. Нажмите **«Остановить»** и дождитесь, пока Docker завершит задачи приложения.
3. Нажмите **«Создать снимок»**.
4. Когда снимок готов, запустите приложение снова кнопкой **«Запустить»**.

Пока идёт снимок, приложение нельзя запустить и нельзя менять его тома.

## История снимков

| Статус | Что значит |
| --- | --- |
| В очереди | Снимок ждёт запуска |
| Создаётся | Идёт копирование томов |
| Готова | Снимок сохранён в хранилище |
| Ошибка | Снимок не создан — например, том используется другим процессом |

Снимок можно перенести на другой сервер — см. [Восстановление и перенос](/docs/backups/restore#тома-приложения).
