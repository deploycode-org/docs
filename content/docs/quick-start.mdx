---
title: Быстрый старт
description: От репозитория на GitHub до работающего приложения на вашем сервере.
icon: Rocket
---

<Steps>
<Step>

### Создайте организацию

Зарегистрируйтесь в [панели DeployCode](https://app.deploycode.ru) и создайте организацию — в ней будут
жить проекты, серверы и SSH-ключи. См. [Организации](/docs/structure/organizations).

</Step>
<Step>

### Подключите GitHub

Установите GitHub App DeployCode на нужные репозитории. См. [Подключение GitHub](/docs/deployments/github).

</Step>
<Step>

### Добавьте сервер

Подключите свою виртуальную машину по SSH от имени обычного пользователя с sudo. DeployCode установит
Docker, Railpack, rclone и Traefik. См. [Подключение сервера](/docs/servers/connect).

</Step>
<Step>

### Создайте проект и приложение

Создайте проект, выберите окружение (например, `production`) и добавьте приложение из репозитория.
См. [Организации и проекты](/docs/structure).

</Step>
<Step>

### Задеплойте

Запустите деплой: DeployCode соберёт образ на вашем сервере и запустит контейнер. Следите за логами
сборки в реальном времени. См. [Сборка и деплой](/docs/deployments).

</Step>
<Step>

### Привяжите домен

Используйте сгенерированный домен или подключите свой — сертификат Let's Encrypt выпустится
автоматически. См. [Домены](/docs/networking).

</Step>
</Steps>
