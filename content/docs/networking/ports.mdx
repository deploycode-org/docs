HTTP-трафик приходит через [домены](/docs/networking) и Traefik. Для остальных протоколов — например,
игровых серверов, MQTT или прямого доступа к базе — порт сервиса публикуется на сервере напрямую.

## Протокол

Поддерживаются **TCP** и **UDP**.

## Режим публикации

| Режим | Как работает |
| --- | --- |
| **Ingress** | Порт открыт на сервере и балансируется между репликами сервиса средствами Docker Swarm |
| **Host** | Порт привязан напрямую к контейнеру на сервере, без балансировки |

<Callout type="warn">
  Опубликованный порт доступен из интернета, если его не закрывает файрвол. Публикуйте порты баз данных
  только при необходимости.
</Callout>
