---
title: Управляемые домены
description: Адреса в зоне deploycode.app, которые DeployCode создаёт сам.
---

**Управляемый домен** — адрес в зоне `deploycode.app`. DNS-запись для него создаёт и удаляет DeployCode,
поэтому настраивать ничего не нужно.

## Как выглядит адрес

Адрес собирается из имени приложения и случайного суффикса:

```text
<имя-приложения>-<6 символов>.deploycode.app
```

Например, `shop-a1b2c3.deploycode.app`. Суффикс делает адрес уникальным; выбрать свой адрес в этой зоне
нельзя — для этого подключите [собственный домен](/docs/networking/custom-domains).

## Когда создаётся

- **Автоматически** — при создании приложения.
- **Вручную** — в настройках доменов приложения. Можно добавить ещё один адрес, например для другого пути.

Для управляемого домена у сервера должен быть публичный IP-адрес: DNS-запись указывает на него.

## HTTPS

Управляемый домен создаётся с сертификатом Let's Encrypt. HTTPS включается сам, когда выполнены оба
условия:

- DNS-запись указывает на сервер — обычно через пару минут после создания домена;
- у приложения была хотя бы одна успешная сборка.

Пока приложение ни разу не собралось, сертификат не выпускается: панель покажет «DNS настроен.
Сертификат выпустим после первого успешного развёртывания». После первой успешной сборки HTTPS
включится сразу. Если позже сборка упадёт, уже выпущенный сертификат продолжит работать.

## Ограничения

| Лимит | Значение |
| --- | --- |
| Управляемых доменов на один сервис | 3 |
| Управляемых доменов на организацию | 25 |

## Удаление и корзина

При удалении домена DeployCode удаляет и его DNS-запись. Если приложение попадает в
[корзину](/docs/structure/trash), его управляемый домен освобождается, а после восстановления выдаётся
**новый** адрес.
