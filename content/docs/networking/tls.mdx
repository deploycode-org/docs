Сертификаты выпускает и продлевает Traefik на вашем сервере.

## Провайдер сертификата

| Провайдер | Когда использовать |
| --- | --- |
| **Let's Encrypt** | По умолчанию. Бесплатный сертификат, выпускается и продлевается автоматически |
| **Без сертификата** | Маршрут не запрашивает сертификат сам. Чтобы работать только по HTTP (например, если TLS завершается на CDN), выключите HTTPS у домена |
| **Свой** | Свой certificate resolver Traefik, настроенный на сервере |

Провайдера можно выбрать при редактировании собственного домена с включённым HTTPS.

## Когда выпускается сертификат

Let's Encrypt проверяет домен по HTTP — запросом на порт **80** вашего сервера. Поэтому:

1. DNS домена должен указывать на сервер.
2. Порт 80 должен быть открыт снаружи.

DeployCode включает HTTPS сам, как только проверка DNS проходит. Для
[управляемых доменов](/docs/networking/managed-domains#https) есть ещё одно условие — хотя бы одно
успешное развёртывание приложения.

Если вы выключили HTTPS у [собственного домена](/docs/networking/custom-domains) вручную, плановые
перепроверки его не включат. Но если статус DNS снова дойдёт до «Настроен» (например, после смены
IP сервера), HTTPS включится автоматически.

## Статус сертификата

В таблице доменов, в колонке **«Сертификат»**, показано, какой сертификат сервер отдаёт на самом деле, и
дата, до которой он действует. Чтобы это узнать, панель открывает HTTPS-соединение с IP-адресом сервера
сервиса на порту 443, передаёт имя домена и читает сертификат. Запросы в приложение при этом не отправляются.

| Статус | Что значит |
| --- | --- |
| **Активен** | Сервер отдаёт действительный сертификат для этого домена |
| **Ждём DNS** | HTTPS включится после успешной проверки DNS |
| **Ждём маршрут** | Маршрут домена ещё не применён на сервере |
| **Ждём сертификат** | Сертификат для домена ещё не выпущен: сервер отдаёт временный сертификат Traefik или не отдаёт никакого |
| **Истёк** | Срок действия сертификата закончился |
| **Недействителен** | Сертификат выдан для другого домена, срок его действия ещё не начался или издателю нельзя доверять |
| **HTTPS выключен** | У домена выключен HTTPS |
| **Удаляется** | Домен удаляется |
| **Не удалось проверить** | Сервер не ответил по HTTPS за 5 секунд или закрыл соединение, либо у сервера не указан публичный IP-адрес |
| **Проверка недоступна** | У домена свой entrypoint вместо `websecure` |

Пока страница открыта, статус обновляется сам: раз в 5 минут, если сертификат активен или HTTPS выключен,
и каждые 30 секунд в остальных случаях. Подробности — пояснение, издатель и время последней проверки —
показаны в окне **«Настройка DNS»**, в блоке **«Сертификат HTTPS»**. Окно открывается из колонки DNS.

## Перенаправление на HTTPS

Когда HTTPS включён, запросы по HTTP перенаправляются на HTTPS.

## Если сертификат не выпускается

См. [Домены и TLS](/docs/troubleshooting/domains).
