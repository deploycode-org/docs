Входящий трафик на сервере принимает **Traefik** и направляет его на нужный сервис по **маршруту**.

## Виды доменов

| Вид | Что это |
| --- | --- |
| [Управляемый](/docs/networking/managed-domains) | Адрес, который выдаёт DeployCode |
| [Собственный](/docs/networking/custom-domains) | Ваш домен, DNS которого вы настраиваете сами |
