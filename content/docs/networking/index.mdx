---
title: Обзор
description: Как трафик попадает в ваше приложение.
---

Входящий трафик на сервере принимает **Traefik**. **Домен** связывает адрес, который вводит
посетитель, с приложением: на какой порт контейнера отправлять запросы, по какому пути и с каким
сертификатом. Домен начинает работать, когда на сервере применён его **маршрут** — конфигурация Traefik.

## Виды доменов

| Вид | Кто настраивает DNS | Пример |
| --- | --- | --- |
| [Управляемый](/docs/networking/managed-domains) | DeployCode, автоматически | `shop-a1b2c3.deploycode.app` |
| [Собственный](/docs/networking/custom-domains) | Вы, у своего регистратора | `shop.example.com` |

Каждое новое приложение сразу получает управляемый домен, так что его можно открыть сразу после первого
деплоя. Собственный домен добавляется в любой момент.

## Настройки домена

| Настройка | Что делает |
| --- | --- |
| **Хост** | Адрес, по которому открывается приложение |
| **Порт контейнера** | Порт, который приложение слушает внутри контейнера. По умолчанию 3000 — см. [Фреймворки](/docs/frameworks#порт--главное-что-нужно-проверить) |
| **HTTPS** | Выпускать сертификат и перенаправлять HTTP на HTTPS — см. [TLS-сертификаты](/docs/networking/tls) |
| **Путь** | Внешний путь на этом домене, например `/api` |
| **Внутренний путь** | Каким путь увидит приложение |
| **Отрезать путь** | Убирать внешний путь из запроса перед передачей в приложение |

Несколько приложений можно повесить на один хост с разными путями: например, фронтенд на `/`, а API на
`/api` с включённым «Отрезать путь».

### Дополнительно

Для тонкой настройки Traefik есть **свой entrypoint** (по умолчанию `web` и `websecure`), **свой
certificate resolver** и **middleware** — ссылки на middleware, которые должны быть определены в
конфигурации Traefik на сервере.

## Где посмотреть домены

Страница **Домены** показывает домены выбранной [области](/docs/structure/scope): всей организации,
проекта, окружения или одного сервиса. Домены приложения — также на его вкладке «Домены».

## Другие протоколы

HTTP и HTTPS идут через домены. Для TCP и UDP используйте [порты](/docs/networking/ports).
