---
title: Готовность к продакшену
description: Что проверить перед запуском приложения для пользователей.
---

## Надёжность

- [ ] В контейнере настроен [healthcheck](/docs/deployments/readiness) — иначе DeployCode не отличит
      работающее приложение от просто запущенного процесса.
- [ ] Постоянные данные лежат в [томах](/docs/deployments/volumes), а не в файловой системе контейнера.
- [ ] Подключён [реестр образов](/docs/deployments/registry), чтобы откатываться без пересборки.

## Данные

- [ ] Включены [бэкапы PostgreSQL](/docs/backups/postgres) с подходящим сроком хранения.
- [ ] Настроены [бэкапы томов](/docs/backups/volumes).
- [ ] Хотя бы раз проверено [восстановление](/docs/backups/restore).

## Окружения

- [ ] Есть отдельное окружение `staging`, изменения проверяются там до `production`.
- [ ] Секреты production не используются в других окружениях.

## Сеть и безопасность

- [ ] Подключён [собственный домен](/docs/networking/custom-domains), сертификат выпущен.
- [ ] Опубликованы только нужные [порты](/docs/networking/ports).
- [ ] Включён [CrowdSec](/docs/servers/firewall).
- [ ] Участникам выданы роли с минимально нужными правами — см. [Роли](/docs/access/roles).

## Наблюдаемость

- [ ] Настроены [уведомления](/docs/observability/notifications) о неудачных деплоях.
